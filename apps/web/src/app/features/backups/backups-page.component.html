Download manager data

The archive includes configuration, user accounts, saved script state, last-known device state, and files in the data folder such as logs. The ZIP is created for this download and is not stored on the server.

Keep the archive and secrets safe

The ZIP contains sensitive configuration and account data. Store it securely. The credential-encryption key and optional OIDC client secret are kept outside the data folder; back them up separately. Without the encryption key, saved MQTT credentials cannot be read.

Manual restore

To restore, stop the manager, extract the archive contents into the configured DATA_DIR, restore required deployment secrets separately, then start the manager again.
