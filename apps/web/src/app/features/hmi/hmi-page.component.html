Before sending an update

Panels need manager HTTP OTA support from the current NSPanel firmware. Unified firmware uses an MQTT topic derived from the assigned device MAC. Set APP_PUBLIC_URL or HMI_PUBLIC_URL to an address reachable from the panel network. Firmware and HMI download links are valid for six hours.
